2. DAS ZENTRALE ZIEL VON ROTFALL
============================================================

ROTFALL soll sich NICHT wie ein statisches Browsergame anfühlen.

Es soll sich wie eine lebendige Welt anfühlen.

Der Spieler soll das Gefühl haben:

"Diese Welt würde auch ohne mich weiterleben."

NPCs haben:

- Berufe
- Wohnungen
- Arbeitsplätze
- Tagesabläufe
- Beziehungen
- Bedürfnisse
- Fraktionszugehörigkeit
- soziale Aktivitäten
- Ziele

Städte haben:

- Wirtschaft
- Produktion
- Handel
- Militär
- Bevölkerung
- Infrastruktur
- politische Interessen

Fraktionen haben:

- Diplomatie
- Kriege
- Bündnisse
- Feinde
- eigene Wirtschaft
- eigene Ränge
- eigene Armeen
- eigene Architektur
- eigene Ausrüstung
- eigene Quests
- eigene Identität

Die Welt verändert sich.

Spieleraktionen haben Konsequenzen.

Große Ereignisse bleiben gespeichert.

Städte können wachsen.

Siedlungen können entstehen.

Fraktionen können stärker oder schwächer werden.

NPCs können sterben.

Karawanen können überfallen werden.

Waren können fehlen.

Kriege können ausbrechen.

Dörfer können gegründet werden.

Der Spieler ist Teil dieser Welt, aber NICHT der Mittelpunkt jeder Simulation.

8. HÄNDLER
============================================================

Händler stehen NICHT 24 Stunden im Laden.

Sie besitzen Arbeitszeiten.

Während Arbeitszeit:

→ Händler befindet sich im Geschäft.

Außerhalb:

→ Händler geht nach Hause / Taverne / andere Aktivität.

Wenn Laden geschlossen:

→ kein normaler Verkauf.

Der Spieler soll beobachten können:

Händler kommt morgens zum Laden.

Öffnet.

Verkauft.

Schließt.

Geht nach Hause.

9. PATHFINDING
============================================================

NPCs dürfen NICHT dauerhaft gegen Türen oder Wände laufen.

Aktuell läuft mindestens ein NPC ständig gegen eine Tür.

Das muss vollständig behoben werden.

NPCs müssen:

- Türen erkennen
- Türen öffnen
- Türen durchqueren
- alternative Wege suchen
- Hindernisse umgehen
- bei blockiertem Weg neu pathfinden

Wenn eine Tür nicht geöffnet werden kann:

→ NPC wartet
ODER
→ sucht alternativen Weg.

KEIN endloses:

laufen → Tür → laufen → Tür → laufen → Tür.

============================================================
17. XP-SYSTEM
============================================================

Das aktuelle XP-System ist falsch.

Wenn NPC A den Gegner tötet:

→ Spieler bekommt NICHT automatisch XP.

XP basieren auf tatsächlichem Schaden / Beitrag.

Beispiel:

Gegner:
100 HP

Spieler:
40 Schaden

NPC:
60 Schaden

Spieler:
≈40 % der XP.

Wenn Spieler:
0 Schaden

→ 0 XP.

Wenn Spieler 10 % Schaden:
→ ungefähr 10 % der XP.

Mehrere Beteiligte:

→ XP nach Contribution verteilen.

Funktioniert für:

- Nahkampf
- Fernkampf
- Magie
- DOT
- Skills
- Fallen
- Begleiter
- mehrere NPCs.

20. ENEMY SCALING
============================================================

Gegner dürfen teilweise mit dem Spieler skalieren.

ABER:

KEIN unbegrenztes Level Scaling.

Jedes Gebiet besitzt eine natürliche Levelspanne.

Beispiel:

Region A:
Level 1–10

Region B:
Level 5–20

Region C:
Level 15–35

Region D:
Level 30–50

Innerhalb dieser Grenzen darf sich die Stärke anpassen.

Spieler Level 12:

→ Gegner z.B. Level 10–14.

Spieler Level 20:

→ Gegner z.B. Level 17–22.

Spieler Level 50:

→ Gegner bleiben beispielsweise maximal Level 25 in diesem Gebiet.

Gebiete behalten dadurch ihre Identität.

Frühe Gebiete werden später leichter.

Keine Endlos-Skalierung.

22. BANDITEN-ÜBERFÄLLE
============================================================

Banditen dürfen NICHT direkt neben dem Spieler spawnen.

Kein:

Spieler läuft um Ecke
→ 10 Banditen erscheinen direkt daneben.

Stattdessen:

Banditen befinden sich vorher in der Welt.

Sie können:

- hinter Bäumen
- hinter Felsen
- im Gebüsch
- neben Straßen
- auf Hügeln
- hinter Gebäuden
- in verlassenen Gebäuden

warten.

Spieler kann sie vorher möglicherweise sehen.

Banditen:

1. positionieren sich
2. warten
3. beobachten
4. erkennen Ziel
5. beginnen Hinterhalt

Dadurch entstehen echte Überfälle.

============================================================

→ STATUS-EFFEKT "VERSKLAVT".

Mögliche Auswirkungen:

- eingeschränkte Bewegung
- keine normale Ausrüstung
- Reputation
- Questzugang
- NPC-Verhalten
- eingeschränkte Freiheit

Wenn Spieler versklavt wurde:

Der Roboter:

- sehr stark
- schwer zu besiegen
- eindeutig als Wächter erkennbar
- eigene Animationen
- eigene Sounds
- eigene Rüstung
- eigene Identität

Er soll nicht wie ein normaler NPC aussehen.

Fernbereich:

NPCs außerhalb relevanter Entfernung müssen nicht vollständig animiert werden.

Weltzustände werden stattdessen mathematisch / datenbasiert simuliert.

- reagieren auf Überfälle
- melden Gefahren
- wechseln Schichten
